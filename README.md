## The two built things

**The portfolio** — nine pages of static HTML on a CDN, generated by `02-site/build_site.py`. Four backend case studies in a fixed three-beat shape (problem → what I did & decided → what came of it), one working contact form, one action. No framework, no dependency tree, nothing to maintain between deploys. The stack rationale in deliverable 11 argues against using my own stack here, and explains why that restraint is the point.

**The study coach** — a grounded revision agent with real memory across sessions, five eval cases written before the build, and append-only guardrails on the one file it must never destroy.

## Where AI did the work

Built with Claude throughout. AI wrote first drafts, tutored me through the parts of my own build I could not explain, and iterated instruction wording for the agent until the guardrails actually held.

What did not come from AI: the proof statement, the stack decision, what the agent is for, the five eval cases, the append-only rule, and every judgement about what to cut. Those are the decisions the deliverables are actually about.
