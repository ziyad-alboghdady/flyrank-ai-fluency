How I work

  • Boundaries firstControllers move HTTP, services hold rules, repositories hold storage. One reason to change each.
  • Schema before queryNormalise, then write the query. Most “performance problems” are modelling problems.
  • Reversible choicesPersistence behind an interface, so today’s shortcut is not tomorrow’s rewrite.
  • I ship what I understandIf I cannot explain a line, it does not go in.
